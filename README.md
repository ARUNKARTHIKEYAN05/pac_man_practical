# Pac-Man

A simple **Pac-Man animation project** built using **HTML and JavaScript**.

The Pac-Man character moves automatically across the browser window and changes its animation image while moving. When Pac-Man reaches the edge of the screen, the direction automatically changes.

## 🚀 Features

* Pac-Man moves automatically.
* Pac-Man animation changes between different images.
* Automatically detects the browser window boundaries.
* Changes direction when reaching the left or right edge.
* Simple HTML and JavaScript implementation.
* No external libraries required.

## 🛠️ Technologies Used

* HTML5
* JavaScript
* PNG Images

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Pac-Man will start moving automatically.

## 🎮 How It Works

The JavaScript program uses:

* `setInterval()` to run the animation repeatedly.
* `position:absolute` to control Pac-Man's position.
* `style.left` to move Pac-Man horizontally.
* `checkPageBounds()` to detect the browser boundaries.
* `pacArray` to switch between Pac-Man images.
